What TEA does for you

  • 🔎

    Finds what's broken

    Opens your running app in a real browser (read-only) and reports crashes, broken links, failing API calls, slow pages and missing images.

  • 🔌

    Checks the wiring

    Matches every call your frontend makes to a route your backend serves, across a separate frontend and backend, in any language.

  • 🧠

    Detects your stack

    Point it at a folder. It finds the apps in it, their frameworks and languages, and where they run. No config.

  • 🧩

    Your own rules, no code

    "No console.log in the code", "Has a privacy page", "No test keys": add with one click or in three steps.

  • 🚦

    A quality gate

    Passed or Failed after every analysis, with Relaxed, Balanced and Strict presets. Blocks a bad deploy in CI.

  • ✍️

    Fix prompts

    Every issue comes with steps to see it and a prompt to paste into Cursor, Claude, Lovable or Bolt. Fix, run again, ship.

How it works

  1. 1

    Add your app

    Add project → Choose folder and detect. TEA shows what it found and suggests the local URL to test.

  2. 2

    Run an analysis

    Watch it brew live. Get the quality gate, the TEA Score, the issue counts and a full report to share.

  3. 3

    Fix the issues

    Filter by severity or area, copy the fix prompt into your AI coding tool, and run again to prove it's fixed.

  4. 4

    Make it yours

    Pick a preset, switch checks on or off, add rules of your own, and set the gate. It's all saved in one file you can commit.

Get started

You need Node.js 20.9+ and git. One command installs, builds and opens the TEA Workbench in your browser.

git clone https://github.com/deepbratt/TEA.git
cd TEA
npm start

Everything runs on your own computer. TEA never installs your app's packages, never writes to your live app, and masks secrets everywhere.
